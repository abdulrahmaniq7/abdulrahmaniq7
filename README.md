# Abdul Rehaman portfolio

A static, single-page portfolio with scroll-aware navigation, project dialogs, community concept tabs, and a phased roadmap.

## GitHub Pages

Upload the CONTENTS of `dist/` to the root of `abdulrahmaniq7.github.io`:

- index.html
- assets/

Do not upload the dist folder itself if GitHub Pages is configured to serve the root. Set Settings → Pages → Deploy from a branch → main → / (root).

No Node build, backend, database, or secret keys are needed. Google Fonts is optional; system font fallbacks are supplied. Contact buttons open an email client; the site does not store enquiries. Replace the email address in index.html to change contact details.

## Content

Past work and the proposed gated community product are distinguished. Product interface illustrations contain no client screenshots or data. Flutter and AI-agent services are presented as scoped offerings, not past delivered case studies.

## Customize

All styles and scripts are in dist/index.html. The portrait, current resume and supplied blueprint are in dist/assets. Replace the resume at the same filename to update the download. Review the blueprint before publicly publishing it.
